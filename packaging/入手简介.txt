PraatSauce 助手 · 试用版入手简介
================================

【一句话上手】
1. 把本文件夹解压到任意普通位置（桌面 / 文档 等），不要放在 C:\Program Files。
2. 本程序已自带 Praat 引擎（praat.exe，与 PraatSauceShell.exe 同在根目录），
   无需另行下载安装，开箱即用。
3. 双击 PraatSauceShell.exe，会打开一个独立的程序窗口（不再走你机器上的浏览器，
   装的是 360、QQ 浏览器还是旧版 IE 都不影响显示）。
4. 若你本机另装了 Praat、想用它，可在界面右上角「设置」→ 点「检测 Praat」
   自动定位，或手动浏览到你的 praat.exe → 保存。之后即可正常使用。
5. 用完直接关闭程序窗口即可，后台服务随之退出，不留进程。

【目录结构】
  PraatSauceShell.exe   主程序（双击启动；已编译，无需安装 Python）
  praat.exe             Praat 引擎（已随包自带，无需另行安装）
  _internal/            程序运行依赖（请勿删除或挪动）
  ui/                   界面文件（启动时读取）
  scripts/              全部 Praat 脚本（位置由程序结构决定，无需配置）
  samples/              示例音频（纯 .wav），可在“声音文件目录”里选它直接试跑
  logs/                 运行日志与报错快照（出问题请把整个目录回传给作者）
  vowel_ref.json        元音参考数据
  入手简介.txt          本文件（快速上手）
  PSShell使用手册.docx  完整使用手册

程序所有路径都相对于「本文件夹所在位置」推导，换机器、换盘符、换文件夹
都能直接用，不写死任何绝对路径。

【出问题怎么办】
打开界面右上角「设置」→ 点「立即自检」：它会检查 Praat 是否真的能执行、
Praat 脚本是否齐全且版本匹配、界面资源是否到位，并直接给出原因。
每次启动还会在 logs/ 下自动写一份自检日志，
把 logs/ 整个目录打包发给我，即可快速定位问题。

如果双击后弹出「无法创建独立窗口」：说明这台机器缺少 WebView2 运行时
（Windows 11 和装过新版 Edge 的 Windows 10 都自带）。程序会自动改用系统
默认浏览器打开，功能不受影响；想恢复独立窗口，装一次
「Microsoft Edge WebView2 Runtime」即可（微软官网免费下载）。
窗口模式的启动过程记录在 logs/shell.log 里。

【关于 Praat】
Praat 是独立的开源声学分析软件，本程序已将它的 Windows 版引擎（praat.exe）
随包放在根目录（与 PraatSauceShell.exe 同级），开箱即用，无需另行安装。
程序启动时会在同级目录自动找到它；你也可以换用本机另装的 Praat：
  (A) 在程序界面「设置」里点「检测 Praat」，会自动定位已安装的
      Praat（默认在 C:\Program Files\Praat\Praat.exe）。
  (B) 手动浏览 / 粘贴任意位置的 praat.exe 路径，保存后即生效。
路径只保存在本机，换机器不影响。

【默认路径说明】
程序所有默认路径（Praat 位置、脚本位置、界面资源）都按“解包所在目录”
动态确定，换机器、换盘符、换文件夹都能直接用，不写死任何绝对路径。

【新手模式】
首次进入向导默认就是“新手模式”（全自动 + 默认值），无需任何配置即可跑。
如需进阶参数，可在界面右上角切换到“进阶”。

【遇到不懂的地方】
界面右上角的「?」是帮助按钮：点一下进入帮助模式，鼠标会变成问号，
这时点界面上任何按钮、参数或空白区域，都会弹出对应的说明——
包括这个参数是什么、结果怎么读、有哪些注意事项，部分条目还附了文献出处。
再点一次「?」或按 Esc 退出帮助模式。
（弹窗盖住顶栏时，按 F1 也能随时打开 / 关闭帮助。）

【已知限制（试用版）】
本试用版为减小体积，未内置 numpy，因此 SHR（次谐谐波比）这一个指标暂不可用，
其余全部功能完整。若你需要 SHR，可联系作者获取内置 numpy 的完整版，
或自行用源码版（需 Python + numpy 环境）运行。

【权限提示】
请勿把本文件夹放在 C:\Program Files 等需要管理员权限的位置，
否则程序可能无法把测量结果写回音频目录。放在普通用户目录即可。

【安全提示】
本程序为绿色无黑窗程序，未做代码签名。Windows SmartScreen / 杀毒软件可能
误报“未知发布者”或拦截运行，属正常现象，并非真有病毒：
  · 若弹出“Windows 已保护你的电脑 / SmartScreen”，点「详细信息」→「仍要运行」即可。
  · 若被杀软隔离，可在杀软里“恢复并加白名单”，或把本文件夹加入排除目录。
  · 右键 PraatSauceShell.exe → 属性 → 勾选“解除锁定”也可减少拦截。
确认来源可信后允许运行即可。
