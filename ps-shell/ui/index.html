第四步 · 查看测量结果

批量跑完先过一眼再导出：每格一个文件，画出所选参数的逐点曲线。 F0 / F1–F5 / B1–B5 取自 wav 旁的对象文件（.Pitch / .Formant）， 其余参数取自第三步的汇总表 out.tsv——缺哪类那几条曲线就是空的。 点格子打开文件详情窗（与九宫格同一套）。

① 选择要查看的参数

仿导出页的八组：每组一个下拉菜单，选中即画进格子（可多组叠加，各按本页范围缩放）；第 5 组起默认不显示，点「更多参数组」展开

每组最多选一个参数，可多组叠加；多条曲线各按「本页范围」单独缩放，颜色对照右侧图例。 灰底竖条是 TextGrid 的音节段（有切分时才画）。

第五步 · 导出数据

把批量运行算出来的逐点测量曲线（不是汇总统计）导出成 CSV。数据来自每个 wav 同目录的 .Pitch / .Formant 对象文件——先批量运行，或在九宫格里「审核完成」/单文件「存盘」，让这些文件落盘。

① 选择要导出的参数

点列标题 = 整列全选 / 取消；列内可逐项勾选（文件、时间为固定两列）

② 导出方式

怎么把逐帧曲线变成 CSV 里的点

③ 文件布局

同一份逐点数据，按哪种方式组织成文件（与上面的导出方式任意组合）

④ 输出

输出为长表：每行一个时间点，列为 file, time_s, 勾选的参数…，多个文件顺序堆叠。UTF-8 带 BOM，Excel 双击即可打开。

不导出标签匹配 的段（正则）；空白段一律不导出；没有 TextGrid 的文件不过滤。

开启后按音频旁同名 .TextGrid 过滤：时间点落在空白段或匹配跳过标记的段（默认 sil）之外的不导出。关闭则导出全部帧。

设置

计算全部由本机 Praat 完成，这个软件只是个外壳。

脚本目录由程序自身结构决定（恒为程序根下的 scripts/），不需要也不允许配置。 点「立即自检」可检查：Praat 能否执行、脚本是否齐全、界面资源是否到位。

支持任意编码与分号分隔：直接粘贴 / 编辑文本，点「从文本框导入」即可生效（未知参数会忽略，缺的用默认值）。

filtered AC 是 Praat 2023 起的推荐基频算法，与主批量一致；raw AC 仅作对照。 青色粗线 = 当前滑块参数算出的预览曲线（叠加在候选上）。拉滑块只改预览， 不会自动存盘——满意后点下面按钮才记入参数并导出。「上限」在 raw 方法里是 硬 ceiling（标准 600Hz），在 filtered 方法里是 pitch top（标准 800Hz，顶部频率 被平滑压制而非硬截断，所以设得比 raw 高）。

共振峰候选
路径

F0 / 共振峰分成两个标签页各管一维：生成候选、存盘、修正互不干扰，切换只重绘、不重跑 Praat； 打开时自动落在九宫格当前模式对应的那一页。两页背景都是窄带语图（25 ms 窗， F0 页语图上限默认 2 kHz，顶部条「显示上限」可改——F0 都在 400 Hz 以下时调小更好看）： F0 页左侧灰刻度是语图、右侧橙刻度是 F0（F0 按自身频率范围自适应铺满，否则 60–400 Hz 会被压成一条扁线）； 共振峰页只标左侧刻度。
图形右上角「▶ 试听」「Praat」只负责听和看，不写任何数据。想用 Praat 手工精修并把结果用起来， 走下面的「修周期 / FormantPath / 导入修正数据」闭环。
保存（F0）/ 存盘（共振峰）：同一个按钮，标签随标签页变，只存当前标签页这一维， 另一页的已存选择不受影响。 F0 页「保存（F0）」记录的是手工修正点 / 修周期标记并立即重导 wav 旁的 .Pitch。 F0 参数取当前实际状态：拉过滑块 → 存预览曲线的那组参数（所见即所得）； 没拉过 → 沿用该文件已存的参数；都没有 → 用第一步批量抽取的默认参数 （「采用这组参数并存盘」效果相同，只是显式一步）；共振峰页没在候选区选过组时会先弹「记哪一组」的选择框。 存盘同时把该文件对应维度的对象重导一次到 wav 旁——批量运行读到这些对象文件就不再重算。
导入修正数据：把你在 Praat 里手动导出的修正文件拿回来。先在旁边下拉框选类型 （「自动识别」一般即可，认 PitchTier 文本 / FormantGrid 文本 / 逐帧 text 三种格式）， 点按钮选文件——导入后该维度整条曲线被替换、候选对比自动撤掉、九宫格那一格同步更新； 记得点「存盘」把结果记下来并导出对象文件。

F0 页 · 点图改 F0（默认不勾选，只在 F0 页生效——改 F0 尽量先用左侧滑块调参， 零星坏点调不动才点图改）：逐点编辑——「相关线」（没拉滑块 = 橙色原始曲线； 拉了滑块 = 青色预览线）上铺满小点（每帧一个 = 原始帧测量点，颜色跟线走）。 点小点 = 删掉这个点（曲线从相邻帧平滑桥接跨过，绝不碰别的帧）， 点灰空心圈 = 恢复它；点空白处 = 加一个 F0 手工点（深紫色，时间自动吸附到最近一帧， 新值只替换那一帧）；无论点加得离曲线多远，都会与曲线平滑连接—— 中间的无声段/空档自动用保单调插值（PCHIP）补上，不会出现孤立的点； 点紫点 = 撤销手工点。「清空手工点」一键全清（含恢复被删的帧）。 加/删只改当前显示，要点「保存（F0）」才落盘（保存后写进 measure.json 并随导出写进 wav 旁的 .Pitch——删的点写桥接值，其余帧一字不动）。整条曲线都不对就用「在 Praat 中修周期」。
F0 页 · 在 Praat 中修周期 → 读回修周期结果：两段式人工修正。点按钮后 Praat 先让你在 PointProcessEditor 里逐周期改脉冲（不需要改就点「跳过脉冲」），接着打开 PitchTier 编辑器修声调曲线 （不需要修就直接点「曲线改好了，导出」）。导出文件直接落在 wav 同目录；回来点「读回」即覆盖图上的 F0 显示，并记 ppfix 标记——之后批量与导出都直接用这份结果、不再重算。
F0 页 · 调基频测量参数（滑块实时预览）：拉滑块看青色预览线（约 0.35 秒防抖）， raw AC 与批量同算法，filtered AC 是 Praat 2023 起的推荐方法；满意后点面板里的 「采用这组参数并存盘」，之后批量都用这组参数；「恢复默认」一键把滑块拉回默认参数 并撤掉青线（只影响显示，不动已存盘的参数）。 出现青线后，点图编辑（加点/删点）都作用在青线上，青线与手工点自动平滑连接， 原橙线降为淡色参考；点「恢复默认」或换参数后青线回到纯预览。

元音音标（顶部短框，非必填）：给这个文件填 1~2 个元音——「音段1」框常驻， 单元音填一段（如 a、ɿ），双元音填两段（如 a、i），「＋」加段、「－」删段； 不填完全不影响其它功能。填了之后，共振峰的优选会按该元音的常见 F1/F2/F3 参考值 （跨语言聚合参考库，男 / 女分开；双元音按首尾两段分别取）参与打分： 九宫格共振峰自动逐音节择优、详情页「生成共振峰候选」标出并预选「推荐」组（蓝框角标）， 都吃这个先验——越贴合参考值的候选越优先。顶部「性别」选男 / 女决定用哪套参考值（未知用通用均值）。 「平滑（Track）」也吃音标：Track 连线本有一个参考频率参数（没音标时按语音段均值自动估计）， 填了音标就改用该元音期望的 F1/F2/F3（双元音取首段），轨迹整体偏向该元音的候选—— 顶部条刚填、还没存盘的音标同样生效；存盘后批量与「审核完成」的平滑写回也带上这份先验。
「生成候选」（左侧候选面板，仅共振峰页；F0 已没有候选对比，参数一律用左侧滑块面板调）： 生成上限 4977~6078 Hz × 数量 4/5/6/7 共 20 组。上限五档是 Praat FormantPath 标准阶梯（ceilingStep=5% 对数步长）以 5500 为中心的 -2..+2 档，相邻档差 5%； 要更外侧的档（4503 低档 / 6390、6718 高档，如女声 F3/F4 偏高时）请点「FormantPath 编辑器」跑全 9 档逐段择优。 （LPC 阶数 = 2 × 数量，两者要配套看， 数量选少了 F1/F2 会糊成一个包络峰，实测数量 4 时 F1 虚高到 1100 Hz 以上）。 共振峰候选用二维表展示：行 = 上限、列 = 数量，点方格即叠加那一组（每行每列互不牵连）； 图上同一上限同色、数量定线型（4 = 实线、5 = 点线、6 = 虚线、7 = 点划线）； 勾选恰好一条才能存盘（勾多了会自动灰掉）；平滑看候选个数：没生成候选 = 平滑基础曲线、只有 1 条候选 = 平滑它（不用勾）、多条且没勾选 = 灰掉（先勾一条）、勾选 1 条 = 平滑它；最终采用哪一组默认按「推荐」组（蓝框角标），存盘时若未指定会追问一次。
共振峰页 · 平滑（Track）：对当前文件跑一次 Praat 的 Viterbi 轨迹跟踪，结果叠加显示 （作用对象的原始逐帧点为淡色细线，彩粗线 = Track 轨迹），不覆盖原始数据，取消勾选即恢复； 平滑与候选共存——平滑作用在哪条候选上，候选叠加不消失，点「恢复默认」可一并撤掉。
共振峰页 · FormantPath 编辑器 → 读回 FormantPath 结果：在自动择优给出的初值上人工复核； 右侧网格每个矩形是一套 ceiling 分析（矩形上的数字 = stress，越小越好），点矩形即把该时段换成那一套， 点「导出并退出」后回来点「读回」。

只看不改：这里不提供改点、平滑、存盘那一套（要改请用九宫格 / 第三步的详情入口）。 顶上只剩语图参数（窗长 / 对比度 / 谱上限），底部那一排存盘 / 修周期 / 导入按钮整条收起。 点标题栏的 ◀ ▶（或按键盘 ← →）直接翻到上一个 / 下一个文件，不用退回九宫格； 中间显示「第 n / 共 m 个」，到头自动禁用。点一个参数名叠一条曲线，最多 6 条， 点左栏已选参数名去掉。颜色即刻度：图左右各若干条纵轴，颜色与曲线一致， 每条曲线按自己的范围铺满图高——所以只能比较「形状与时间位置」，不能跨参数比高低。
数据来源：F0 读 wav 旁的 .Pitch，F1–F5 / B1–B5 读 .Formant，其余各列读 汇总表 out.tsv。某一列全是空的 = 还没跑出那一列（先在第三步批量跑一次）。

批量重切分（覆盖选中文件的 TextGrid）

用下面进阶参数重新切分勾选的文件，覆盖同名 .TextGrid（无论是否曾手工精修）。参数仅本次用，不改全局设置。

切分详情 ·

浏览器内直接编辑（推荐）：在波形上点空白处插入一个音节边界（把当前段一分为二）； 点已有的边界竖线可删除它（合并相邻两段）；按住边界拖动可微调位置； 下方段标签芯片：单击在「sil ↔ 音节」之间切换（会记住该段原来的文字）， 双击可任意改标注文字（Enter 或点别处提交，Esc 取消，留空即 sil）。
改完点 「保存 TextGrid」 即把结果写回同目录同名文件（无需启动 Praat）。
仍想用专业编辑器？点「在 Praat 中打开」会启动本机 Praat 载入 wav+TextGrid：在编辑器里改完边界/标签后， 点 Praat 里的 「保存并退出」 写回文件，再点本页 「刷新（从文件读取）」 把结果拉回网页。 删除边界更宽容：在已有边界左右 15ms 内 点击即可删除（合并相邻两段）。

还没完成共振峰和基频审核

继续 = 这些文件从头算一遍 F0/共振峰再算其余参数；已审过的文件不会重算。建议先退回，把剩下的文件在九宫格里审完（F0 页 / 共振峰页各自点「保存」，或整批点「审核完成」标记过关）。
